Academic Project Demonstration Disclaimer

PriceWise is a college project prototype built with Python Flask, SQLite, RapidFuzz, HTML5, CSS3, Vanilla JavaScript, and Chart.js. All displayed store prices, discounts, and seller comparisons are sample demonstration data. The application does not scrape live third-party e-commerce platforms and is designed with clean modular interfaces ready for official partner API integration in the future.
